# Tanzanite Trail

Full-colour Python 3 neon light-cycle arcade for ElbowOS.

Steer a glowing gold bike that leaves a solid violet/cyan trail. Collect glowing orbs for score. Avoid the edges and your own trail. Speed increases as you score.

Arrow keys / WASD to turn. R to restart.

## Play

```
pip install -r requirements.txt
python3 tanzanite_trail.py --play
```

## Record a 9:16 reel

```
python3 tanzanite_trail.py --record
```

Outputs a 15-second 1080x1920 MP4 with autoplay AI.
